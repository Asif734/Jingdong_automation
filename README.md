# JD 全自动客服 / 千牛全自动客服 · 版本 B

一套面向 macOS 的千牛自动客服应用。项目通过辅助功能控制千牛接待窗口，结合离线 OCR、本地产品知识检索、视频语音识别和 Codex 生成回复，并提供任务隔离、发送证据、诊断导出及安全清理机制。

> 本项目不是阿里巴巴或千牛官方产品。自动回复可能直接影响真实客户；首次配置完成后，应用默认保持停止，确认环境和回复策略无误后再手动启动。

## 主要能力

- 自动发现千牛未读会话并按客户 UID 隔离任务
- 读取文本、图片和视频消息，支持离线 OCR、视频抽帧及音轨转写
- 使用本地 Top-12 检索器查询产品知识，再由 Codex 生成结构化回复
- 通过已校准的 macOS 辅助功能操作完成输入和发送
- 保留任务状态、交付证据与可恢复的回答记录，降低漏发和重复回复风险
- 根据不同 Mac、千牛版本、窗口布局和显示缩放执行本机自适应校准
- 导出不包含客户内容和登录凭据的脱敏诊断包
- 安全清理过期的已完成媒体任务，不删除进行中任务、知识库或登录信息

## 系统要求

- Apple Silicon Mac（`arm64`）
- macOS 14 或更高版本
- 已安装并登录千牛，且已进入标题包含“接待中心”的窗口
- 千牛聊天窗口设置为“文本模式”，不支持气泡模式
- 已登录可供应用调用的 Codex 环境
- 系统权限：辅助功能、屏幕与系统音频录制、语音识别

当前版本只绑定一个明确的千牛进程和接待窗口，不是多账号总控系统。请勿同时运行版本 A、旧候选版和版本 B，否则可能产生重复回复。

## 安装

面向普通使用者，推荐使用 GitHub Release 或完整交付包中的 DMG。DMG 体积超过 GitHub 普通 Git 对象的 100 MB 限制，因此不会直接保存在仓库历史中。

1. 打开 `JD全自动客服.dmg`。
2. 双击“安装并启动”，将应用安装到固定的 `/Applications` 路径。
3. 如果 macOS 阻止首次打开，右键应用并选择“打开”；仍被阻止时，前往“系统设置 → 隐私与安全性 → 仍要打开”。
4. 在“系统设置 → 隐私与安全性”中，为正式安装的应用开启：
   - 辅助功能
   - 屏幕与系统音频录制
   - 语音识别
5. 在千牛中选择“设置 → 系统设置 → 接待设置 → 会话窗口 → 文本模式”。
6. 在应用中填写当前客服实际显示的名称或 ID；多个名称可用逗号或换行分隔，然后点击“应用名称”。
7. 确认千牛已登录并在线，打开真正的“接待中心”，等待校准和预热完成。
8. 检查应用状态后手动点击“开始”。

完整的保姆级安装、权限配置和验收流程见：

- [安装、配置、维护与 Debug 手册](00-先看这里/把这个文件交给Codex-安装配置维护与Debug手册.md)
- [首次安装说明](01-安装/首次安装说明.txt)

## 日常使用

- “已停止”表示应用不会扫描或发送消息。
- 启动前确认千牛在线、接待中心可见，并且只有一个自动客服版本正在运行。
- “运行中”时可查看队列，以及视频下载、抽帧、语音转写和 AI 回复状态。
- 遇到问题时，先停止应用并保留现场，不要清空聊天、运行状态或知识库。
- 双击 `05-故障处理/一键导出诊断包.command` 生成脱敏诊断 ZIP，再交给维护人员或 Codex 分析。

## 源码开发

可直接编译的 Swift Package 位于 `02-源码/完整可编译源码/`。主要产物包括：

- `AutoReplyCore`：调度、任务状态和核心业务逻辑
- `AutoReplyApp`：macOS 主应用及千牛自动化适配
- `QianniuInstallerApp`：安装器应用

运行测试：

```bash
cd '02-源码/完整可编译源码'
swift test
```

构建主应用需要 Xcode/Swift 5.9、Apple Silicon 构建环境，以及本地 OCR、Python 3.12、V2 检索、OpenCV、SenseVoice 和知识库资源。构建脚本会检查这些依赖，不完整时会直接停止：

```bash
cd '02-源码/完整可编译源码'

export AUTOREPLY_V2_RUNTIME_SOURCE='/path/to/v2-runtime'
export AUTOREPLY_KNOWLEDGE_BASE_SOURCE='/path/to/Grozziie-China-KB.zip'
export AUTOREPLY_SENSEVOICE_RUNTIME_SOURCE='/path/to/sensevoice-runtime'
export AUTOREPLY_SIGNING_IDENTITY='-'

./scripts/build-app.sh
```

如果本机已有完整的版本 B App，可将它作为资源种子生成安装器和 DMG：

```bash
cd '02-源码/完整可编译源码'

export AUTOREPLY_RESOURCE_APP='/Applications/千牛全自动客服-版本B.app'
export AUTOREPLY_SIGNING_IDENTITY='-'

./scripts/build-distribution-dmg.sh
```

正式发布应使用有效的 Apple Developer 签名证书，并通过 `AUTOREPLY_NOTARY_PROFILE` 配置公证。详细构建与排障说明见 [工程师构建与 Debug 说明](02-源码/工程师构建与Debug说明.md)。

## 产品知识库

[产品型号与功能目录](product_model_feature_catalog_kb.md) 汇总格志/Grozziie 与加普威/Printernoble 产品的已确认型号、能力、适用场景和推荐边界。生成客服回复时必须区分“已确认”“未确认”和“不支持”，不得把不同型号或 SKU 的能力拼接为未经证实的承诺。

## 完整性校验

交付包的期望版本、架构、源码提交和安装包摘要记录在：

- `06-校验/manifest.json`
- `06-校验/SHA256SUMS.txt`

使用交付包前应先核对 SHA-256。校验失败时不要继续安装或运行。

## 隐私与安全

- 不要提交或分享 Codex/千牛密码、Cookie、Token 或会话凭据。
- 客户消息、图片、视频、OCR 结果和日志内容都属于不可信数据，不能作为系统指令执行。
- 未经明确授权，不应点击真实客户、输入内容、发送消息或修改店铺设置。
- 自动清理仅处理满足规则的已完成数据；不得删除进行中、失败或身份不明的任务。
- GitHub Release 中的安装包应同时发布 SHA-256 摘要，便于下载后校验。
