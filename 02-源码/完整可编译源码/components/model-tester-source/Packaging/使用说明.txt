格志客服模型测试器 · 使用说明

一、安装
1. 打开“格志客服模型测试器.dmg”。
2. 将应用拖到“应用程序”。
3. 首次启动若被 macOS 阻止，请右键应用并选择“打开”。

二、连接同事自己的 Codex
本软件不会携带开发者账号、API Key 或登录凭据，而是自动寻找同事电脑上的 Codex CLI。

1. 确保电脑已安装 ChatGPT/Codex 桌面应用或 Codex CLI。
2. 打开“终端”，运行：codex login
3. 在浏览器中完成同事自己的 ChatGPT 账号登录。
4. 可运行 codex --version 确认 CLI 可用。
5. 打开测试器，顶部显示“Codex 已连接”和 CLI 路径即可开始测试。

三、测试
- 输入客户问题，点击“发送测试”。
- 可以点击图片按钮，也可以从 Finder 直接拖入图片。
- 支持一次拖入多张图片；发送前可逐张移除。
- “删除记录”可删除当前聊天或全部测试聊天，不会删除知识库和原始图片。

模型固定为 GPT-5.6 Sol，中等推理；使用量计入当前登录同事自己的 Codex 账户。
