# 千牛未读助手（一期连接版）

只在点击“查找并打开”时检查当前可见接待列表的头像红点，选择最上方的可靠目标，读取完整 ID，打开并核对聊天顶部完整 ID，随后按一期版现有“识别千牛主聊天区”按钮一次。不后台轮询、不滚动、不清除筛选、不读取聊天正文。后续 OCR、增量入队、AI 回复和发送仍由一期版原流程处理。

连接目标是 `/Applications/AI客服三件套-通用复制实验版.app/Contents/Resources/Components/千牛主聊天区OCR-通用复制实验版.app`。未运行时直接打开这个已有组件，不经过会新开实例的外壳；已运行时复用。识别按钮按 AX 标签定位，不使用固定坐标。没有红点、用户核对失败、一期版忙/多实例/多窗口/按钮缺失时停止。准备好按钮后再次核对千牛当前 UID，只做一次 AXPress，不重试结果不确定的操作。界面“已触发”仅表示按钮调用成功，不代表后续 AI 回复或发送已完成。

一期版源码、安装包及封存包均不修改。连接前的未读助手安装包保留在 `work/qianniu-unread-assistant/pre-link-installed.app`。

### 2026-08-26 标题省略修复

左侧列表通过“正在接待买家列表”的 AX 结构独立定位，不再要求聊天顶部已有完整 ID。列表每行完整 ID 由 AX 提供，红点由截图像素判断，无固定屏幕坐标。

点击后若顶部名字省略，助手尝试打开当前标题对应的资料窗，通过新资料窗 AX 标题读取完整会员名，然后关闭资料窗并核对窗口/列表/标题未改变。完整会员名必须与列表精确一致；同前缀多客户、已有资料窗、读取失败或身份变化时停止，不根据省略前缀猜 ID。资料窗自动读取的真实成功路径尚待完成验证，详见 LIVE-QA.md。

## 构建

要求 macOS 14+、Swift 6，零第三方依赖。当前构建环境 Swift 6.3.3、Apple Silicon。

```sh
bash work/qianniu-unread-assistant/scripts/build-app.sh
```

更新安装必须先退出助手并确认 `UnreadApp` 进程结束，再执行（一次只运行一个安装器）：

```sh
bash work/qianniu-unread-assistant/scripts/install-app.sh
```

安装器遇到运行中的进程会拒绝更新；先在独立临时目录复制和校验完整签名包，再整体移动替换。旧包保留在 `installation-backups/`，不原地覆盖正在运行的可执行文件。不要在应用运行或尚未退出完时直接复制二进制或重新签名安装目录。

输出 `work/qianniu-unread-assistant/output/千牛未读助手.app`，bundle ID `com.local.qianniu-unread-assistant`。脚本先测试，再构建 release，使用本机现有 `Apple Development: Chu Ye Shi (6Q9HFP6LJJ)` 签名并验证；不导出私钥，不修改其他应用。签名身份缺失时明确失败。控制者检查目标不存在后，才安装到 `/Applications/千牛未读助手.app`。

## 使用与权限

打开千牛接待中心，保持窗口未最小化。打开助手并点击“查找并打开”。可用底部设置链接打开对应系统面板，手动为此新应用启用“辅助功能”和“屏幕与系统音频录制”；这两个权限与旧应用独立。授权后重新打开助手。设置链接只打开面板，应用不改系统权限，也不自动弹出授权请求。

没有红点时只报告“当前可见列表未检测到红点”；结构不可识别或任何可见候选行身份缺失、截断、歧义、重复时明确报列表识别不完整，不跳过该行或视为没有未读。应用仅有一个主窗口，运行时禁用查找按钮，不能从多个窗口同时发起操作。打开前会重复截图和读取列表；捕获期间列表/窗口改变会停止。激活后再次核对红点，点击前同步重新定位相同完整 ID；按实时 AX 行位置点击，系统命中必须核对千牛进程、完整用户 ID、行位置和所属接待窗口，不依赖可能重建的 AX 对象相等。点击后仅完整 ID 精确一致才报告已打开。

## 隐私和诊断

截图仅在内存处理，不落盘。仅读取列表行容器的身份字段、结构性控件标签及与聊天标题控件对齐的标题字段；不读取消息正文/输入框值。助手本身没有网络请求、AI API 或业务队列；触发的一期版继续使用自身原有流程及权限。

首次有权限的检查会覆盖写入一个文件：

`~/Library/Application Support/QianniuUnreadAssistant/last-diagnostic.txt`

仅包含最后一次窗口编号、时间、AX节点ID/父节点ID/角色/矩形及少量结构锚点标记；无 UID、聊天文本或截图。可用于排查千牛不同版本的辅助功能结构。

## 测试与边界

```sh
swift test --package-path work/qianniu-unread-assistant
```

测试直接加载不可变证据截图，同时覆盖第1/5/10行、窗口平移、2倍像素、列表重排、多个红点、红头像/计时/全局徽标排除、任意完整ID、截断/歧义拒绝、截图期间移动、权限失败和核对失败。外部AX/截图/点击边界在编排测试中使用测试替身，不执行真实UI。

红点形状和头像角标区域根据所供千牛截图校准；不承诺未知布局/主题均适用。任意头像恰好包含同位置同大小的红圆图案在纯图像上不可区分，因此本版不是千牛业务未读状态的语义API。不同千牛结构需要通过诊断验证；完整端到端成功需用户授权及真实红点可用时进行。不把打开聊天视为已回复。
# 失败恢复补充（2026-08-26）

仍然是点击一次处理一次，不后台扫描。点开客户后，若一期版尚未触发成功，会保留该客户 ID；下次点击继续核对并交接，不再依赖已经消失的红点。记录保存在 `~/Library/Application Support/QianniuUnreadAssistant/pending-handoff.json`。

若已经尝试点击一期按钮但结果不确定，不会自动再按一次；查看一期版后，可用“已核对／放弃本次，清除待处理标记”。清除的是助手的交接标记，不删除聊天记录。

截图超过 5 秒会退出等待。若系统截图请求仍未返回，后续点击会提示等待或重开助手，不累积截图任务。构建前需退出未读助手，安装继续使用 `scripts/install-app.sh`。
