# 请自动完成千牛视频直链测试

用户希望验证当前 Mac 是否能通过千牛播放器日志中的临时视频资源地址直接下载客户测试视频。

请严格按以下边界执行：

1. 不修改千牛、正式自动客服程序或测试器源码。
2. 不发送任何客户消息，不输入聊天内容。
3. 不输出、复制、保存或展示临时签名视频地址，也不要展示千牛原始日志。
4. 打开同目录的“千牛视频直链测试器.app”。
5. 确认千牛已经运行，并在接待中心打开包含测试视频的客户聊天框。
6. 在测试器中点击“开始监听”，然后只点击聊天框中央的测试视频一次；不要点击右侧消息记录或商品区域。
7. 等待测试器显示“测试通过”或“测试未通过”。
8. 读取桌面最新的“千牛视频直链测试结果-*.zip”中的脱敏 `测试报告.md` 和 `result.json`，核对：
   - result 是否为 passed；
   - HTTP 是否为 200 或 206；
   - 文件是否有正数时长、正数尺寸、视频轨道及 SHA-256；
   - 结果目录中不存在 `auth_key=`、`sessionkey=`、`securityUID=` 或完整视频地址。
9. 最后只向用户汇报：PASS/FAIL、macOS、芯片架构、千牛版本、发现耗时、下载耗时、视频时长、分辨率、编码和失败原因。不要报告临时地址。

若电脑操作能力不可用，只需让用户手动完成第 4–7 步，其余验证继续由你完成。失败时保留结果 ZIP，不要删除证据，也不要尝试开启自动客服。
